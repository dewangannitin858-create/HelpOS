# HelpOS

**HelpOS** is an upgraded fork of [StudyOS](https://github.com/Arshhabh/StudyOS) designed as an all-in-one student productivity workspace, enhanced with a built-in **Attendance Calendar** for effortless class tracking, percentage monitoring, and daily student organization.

---

## Features

- **Student Workspace:** All core study and organization tools inherited from StudyOS.
- **Attendance Calendar *(In Progress)*:**
  - Track daily class attendance (Present, Absent, Cancelled).
  - Automatic subject-wise attendance percentage calculation.
  - Visual monthly calendar view to stay on top of attendance goals.
